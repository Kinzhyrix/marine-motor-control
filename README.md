# Marine Motor Control — Wiring & Starter Simulator

Live page: https://kinzhyrix.github.io/marine-motor-control/

Interactive training reference for motor control on large merchant vessels:
full-scale configurable starter simulator (supply voltage/frequency, star/delta,
DOL, reversing, star-delta, soft starter, VFD, control voltage), panel wiring layout,
wire schedule, ladder diagrams, ship-specific rules and fault-finding.

Generic training material: always follow the vessel's approved drawings and class rules.
